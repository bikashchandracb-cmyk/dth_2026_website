# Advantages of Open Source Software
As a student, I use open source software for my studies. I value it not only because it is free, but because its source code is available. People can study, share and modify it under the terms of its licence (Open Source Initiative, 2024).

One advantage is lower cost. Students need software for writing, research and data analysis, but paid programmes can be expensive. LibreOffice allows users to write documents, create presentations and make spreadsheets without paying for a licence (The Document Foundation, n.d.).

Open source software also gives users freedom and control. They are not fully dependent on one company and may change the software if the licence allows it. It encourages collaboration too. People can report errors, translate programmes, share ideas and improve the code.

I experienced this when I used Orange Data Mining in my first-semester Applied Qualitative Research Methods course. We connected widgets and explored data. I could practise data analysis without advanced programming skills or paying for software.

Open source tools are useful in education and research. Students can develop digital skills, while researchers can share their methods. Public organisations can also reduce costs and have more control over their digital systems.

For me, the main advantage is that open source software creates opportunities to learn, collaborate and use digital tools.
