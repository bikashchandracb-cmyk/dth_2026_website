# Advantages of Open Source Software

Most people think about the price first. Many open source tools are free to download, and this really helps a student. Anyone in any country can use the same tools. LibreOffice can replace Microsoft Office for writing reports, and Zotero keeps my references in order without any licence fee. But for me the price is not the main point.

The bigger advantage is that anyone can read the code. With a closed program I have to trust the company when it says what the program does. With open source, a person with the right skills can check it. This matters in research, because I must be able to explain how I got my results. In my first semester I used Orange for data mining in Applied Qualitative Research Methods, and every step used a method I could look up and describe in my report (Bioinformatics Laboratory, University of Ljubljana, n.d.).

Open source can also survive its makers. Linux started in 1991, when a Finnish student called Linus Torvalds shared his hobby project online and volunteers from many countries helped to build it. If a developer stops working, other people can take over, because the code is public. This is useful for a municipality too, since it does not depend on one supplier for many years.

So the main advantage for me is freedom. I can understand the tools I use, share them and improve them, and this is more than saving money.
